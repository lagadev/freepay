Authentication Bearer Key

প্রতিটা Brand-এর নিজস্ব API key আছে (Brand পেজে পাবেন)। ইনভয়েস তৈরি ও SMS ingest — দুটোতেই এই key লাগবে:

Authorization: Bearer YOUR_BRAND_API_KEY

Webhook Listener callbackUrl

ইনভয়েস verified হলে callbackUrl-এ signed POST যায়। ব্যালেন্স/অর্ডার আপডেট করার আগে অবশ্যই X-Signature (HMAC-SHA256, আপনার Brand API key দিয়ে সাইন করা) ভেরিফাই করুন।

const crypto = require('crypto');
app.use(express.json());

app.post('/callback', async (req, res) => {
    const raw = JSON.stringify(req.body);
    const expected = crypto.createHmac('sha256', process.env.BRAND_API_KEY)
        .update(raw).digest('hex');

    if (req.headers['x-signature'] !== expected) {
        return res.status(401).send('bad signature');
    }

    const { event, reference, trxId, amount } = req.body;
    if (event === 'invoice.verified') {
        // mark order `reference` as paid, store trxId, credit amount, etc.
    }
    res.sendStatus(200);
});
import hmac, hashlib, json
from flask import Flask, request

app = Flask(__name__)
BRAND_API_KEY = "YOUR_BRAND_API_KEY"

@app.route("/callback", methods=["POST"])
def callback():
    raw = request.get_data()
    expected = hmac.new(BRAND_API_KEY.encode(), raw, hashlib.sha256).hexdigest()

    if request.headers.get("X-Signature") != expected:
        return "bad signature", 401

    data = request.get_json()
    if data.get("event") == "invoice.verified":
        # mark order data["reference"] as paid, store data["trxId"], etc.
        pass
    return "", 200

Verify Transaction ID POST

POST /api/invoices/:id/verify
{ "trxId": "8N7A1B2C3D", "senderNumber": "01712345678" }

TrxID শুধু তখনই ম্যাচ করবে যদি এটি এই ইনভয়েসের নিজের ১৫ মিনিটের উইন্ডোর মধ্যে আসা SMS-এর সাথে মেলে — অর্থাৎ শেষ ১৫ মিনিটে "verify" হওয়া লাগবে।
